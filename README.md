# Viaalink Relay — releases

Downloads of Viaalink Relay: the `viaalink-relay` binary for Linux, macOS and
Windows. Each release has a `viaalink-relay-<version>-checksums.txt` with the
SHA-256 of every archive.

Viaalink Relay is proprietary software, not open source. Every archive contains
its license (`LICENSE`) and the notices of the open-source parts it uses
(`THIRD_PARTY_NOTICES.txt`).

Docs: https://viaalink.com/docs/relay
